# make-knowledge-cards

一个 AI Skill:把用户粘贴的文章或本地 Markdown/TXT 文件转换成知识卡片,用于学习和复习。

## 解决什么问题

读完一篇好文章,过几天就忘得差不多——因为缺少提炼和复习的载体。这个 Skill 把一篇文章自动提炼成一组**知识卡片**:每张只讲一个知识点,配通俗解释和例子/自测题,方便你快速回顾、自测和记忆,把"读过"变成"记住"。

同时它严格保证可信度:所有内容必须出自原文,不编造、不注水;原文知识不够时宁可少做,也不强行凑数。

## 主要功能

- **输入**:用户直接粘贴的文章正文,或本地 `.md` / `.txt` 文件
- **输出**:通常 5~8 张知识卡片,每张包含四个字段:
  - **标题** — 一句话点明主题(不超过 25 字符)
  - **核心知识** — 知识点本身,使用原文的事实和术语
  - **简明解释** — 通俗讲清"为什么是这样",允许类比但会标注"(类比)"
  - **例子或自测问题** — 原文有例子则借用(标注"出自原文"),否则出一道自测题并附参考答案
- **质量保证**:
  - 一张卡片只讲一个知识点
  - 同义去重,不产出重复卡片
  - 不引入原文之外的事实、数字、人名、结论
  - 低知识密度文本(如抒情散文、广告)只产出 1~2 张并说明理由,不凑数
- **暂不支持**:网页抓取、PDF、Anki、图形界面

## 安装方法

本 Skill 是纯指令型 Skill(无脚本依赖),把 `skills/make-knowledge-cards` 目录复制到 AI 助手的 Skill 目录即可:

- **WorkBuddy 用户级**(所有项目可用):复制到 `~/.workbuddy/skills/`
- **WorkBuddy 项目级**(仅当前项目):复制到项目根目录的 `.workbuddy/skills/`
- **Claude / 其他兼容 Agent Skills 的运行时**:复制到对应的 skills 目录,由运行时自动加载 `SKILL.md`

`agents/openai.yaml` 为可选元数据,供支持该格式的 OpenAI agent 运行时识别,不影响核心功能。

## 使用方法

安装后,直接对 AI 助手提出请求即可,例如:

> 帮我把这篇文章做成知识卡片:[粘贴文章正文]

或:

> 把 `notes/pomodoro.md` 转成知识卡片

助手会按 SKILL.md 的流程执行:通读原文 → 判断知识密度 → 提取并去重知识点 → 逐张写卡 → 自检后输出。默认在对话中直接输出;也可以要求写入文件(会保存为"原文名-cards.md")。

## 输入输出示例

**输入**(节选,完整文件见 `examples/inputs/02-教程-番茄工作法.md`):

> 番茄工作法是一种简单的时间管理方法,由弗朗西斯科·西里洛在上世纪八十年代提出,名字来自他当年用的番茄形状厨房计时器。基本流程只有四步……

**输出**(实际运行结果节选,完整结果见 `examples/outputs/02-教程-番茄工作法-cards.md`):

```markdown
## 卡片 1:番茄工作法是什么?

**核心知识**:番茄工作法是一种简单的时间管理方法,由弗朗西斯科·西里洛在上世纪八十年代提出,名字来自他当年用的番茄形状厨房计时器。

**简明解释**:理解这套方法的起点:它不是复杂的系统,而是围绕一个厨房计时器建立的极简专注流程,核心结构始终是"专注一段+休息一段"。

**例子/自测**:自测:番茄工作法由谁提出?"番茄"这个名字来自什么?(参考答案:弗朗西斯科·西里洛;他当年用的番茄形状厨房计时器)
```

更多真实示例(含低知识密度文本的处理)见 `examples/` 目录:

| 输入 | 输出 | 结果 |
|------|------|------|
| `examples/inputs/01-科普-睡眠与记忆.md` | `examples/outputs/01-科普-睡眠与记忆-cards.md` | 7 张卡片 |
| `examples/inputs/02-教程-番茄工作法.md` | `examples/outputs/02-教程-番茄工作法-cards.md` | 7 张卡片 |
| `examples/inputs/03-散文-秋日.txt` | `examples/outputs/03-散文-秋日-cards.md` | 低知识密度,仅 1 张并说明理由 |

## 目录结构

```
skills/make-knowledge-cards/
├── SKILL.md            # Skill 定义(核心)
└── agents/
    └── openai.yaml     # OpenAI agent 运行时元数据(可选)
examples/
├── inputs/             # 测试文章(科普 / 教程 / 散文)
└── outputs/            # 对应生成的卡片
```
