# Make Knowledge Cards

## Overview

把一篇文章提炼成知识卡片(通常 5~8 张),帮助用户学习和复习。每张卡片只讲一个知识点,内容严格来自原文,不编造;原文知识不足时不强行凑数。

## 支持的输入

- 用户直接粘贴在对话中的文章正文
- 本地 `.md` 或 `.txt` 文件(用文件读取工具读取内容)

**不支持**(遇到时明确告知用户,不要尝试变通):网页链接抓取、PDF 文件、Anki 导出、图形界面。如用户只有这些形式,请其粘贴正文或转为 `.md`/`.txt` 后再试。

## 工作流程

### 1. 获取并通读原文

粘贴文本直接使用;文件路径先读取全文。通读后判断知识密度:

- **可操作判据**:全文中可验证的事实、概念、原理、方法、步骤、关键结论加起来不足 5 处,即视为低知识密度。
- 纯叙事、广告、情绪表达、极短文本通常都属于此类。
- 低知识密度文本:说明理由,产出 0~2 张卡片即可,不要凑数。抒情/叙事文没有知识点可提取时,可做 1~2 张"文本分析卡"(分析其写法或主题),但必须在提取说明中注明该卡片为解读;一张都做不出时建议放弃,由用户决定是否继续。

### 2. 提取知识点

- 逐段通读,列出原文中所有值得记住的事实、概念、原理、方法、步骤、关键结论。
- 只提取真正重要的知识,忽略:客套话、过渡句、重复强调、琐碎细节、举例中的次要信息。
- **同义去重**:不同段落反复说的同一件事,合并为一个知识点,保留信息最完整的表述。
- 每个候选知识点必须能在原文中找到明确出处,找不到出处的一律丢弃。

### 3. 筛选数量

- 目标产出 **5~8 张**。
- 候选超过 8 个:先合并相近的,再按重要性排序取前 8 个。
- 候选不足 5 个:有几个做几个,**不拆分同一点、不注水**。任何最终产出少于 5 张的情况,都必须在末尾的提取说明中写明"原文可提取的知识点有限,仅产出 N 张"及原因。

### 4. 逐张写卡片

每张卡片包含四个字段,一卡只讲一个知识点:

| 字段 | 写法 |
|------|------|
| **标题** | 一句话点明主题,可带"为什么/是什么/怎么做"提示;不超过 25 个字符(含标点),超出就改写压缩 |
| **核心知识** | 该知识点本身,用原文的事实和术语,1~3 句,是卡片的主体 |
| **简明解释** | 讲清"为什么是这样"或"意味着什么",帮助理解而非复述。允许演绎推理和类比,但不得引入原文之外的新事实、数字、人名;用了类比要在该类比表述后紧跟括注"(类比)" |
| **例子/自测** | 二选一,格式固定为:<br>· 原文有合适例子 → `例子(出自原文):……`<br>· 原文没有合适例子 → `自测:问题……(参考答案:……)`,参考答案含多项时用 `;` 分隔<br>不要硬编例子 |

**完整示例**(供把握详略和格式):

```markdown
## 卡片 3:深睡眠巩固什么记忆?

**核心知识**:深睡眠(慢波睡眠)主要巩固陈述性记忆,即事实、概念、事件这类可以被"说出来"的知识。在慢波睡眠中,海马体会快速"重演"白天经历过的神经活动模式,皮层在反复播放中逐渐学会这些内容。

**简明解释**:可以把海马体重演理解为"把一天的录像快放一遍"(类比),皮层通过反复观看把内容学会——所以背单词、记概念这类学习,依赖的是深睡眠。

**例子/自测**:自测:"事实、概念、事件"这类可被"说出来"的记忆叫什么?主要由哪种睡眠巩固?(参考答案:陈述性记忆;深睡眠/慢波睡眠)

---
```

### 5. 输出前自检

逐条核对,发现问题就改掉再输出:

- [ ] 每张卡片只讲一个知识点,且能在原文找到依据
- [ ] 没有原文之外的新事实、数字、人名、结论;数字和单位已与原文逐一核对(含例子/自测中出现的);类比均已标注
- [ ] 没有内容重复的卡片
- [ ] 数量在 5~8 张;不足 5 张时已写明原因
- [ ] 每个字段齐全,例子/自测使用了规定的固定格式
- [ ] 语言是用户的语言(中文输入→中文卡片)

## 输出格式

默认直接在对话中用 Markdown 输出,不写入文件。每张卡片一个区块,卡片之间用 `---` 分隔,最后一张卡片之后统一附一段提取说明(共几张、筛选取舍的理由;不足 5 张时必填原因):

```markdown
## 卡片 1:标题

**核心知识**:……

**简明解释**:……

**例子/自测**:……

---

## 卡片 2:标题

……

---

> 提取说明:共产出 N 张卡片,……
```

用户明确要求写入文件时:文件名用"原文名-cards.md",目录不存在则创建,提取说明随卡片一并写入文件末尾;写入后在对话中只给出文件路径和卡片标题列表,不再重复卡片全文。
